# Точный аналог из опубликованной камфорной серии 2018 года

Источник: [Kovaleva et al., DOI 10.1039/C8MD00442K](https://pubs.rsc.org/en/content/articlepdf/2018/md/c8md00442k), таблица 1. Для соединения **9** там приведены CC50 1430,1 мкМ, IC50 5,1 мкМ, опубликованный SI 280; отношение средних составляет 280,411765. Для соединения **10** опубликовано 287,8 / 11,1 = 25,927928, что совпадает с независимой обучающей меткой 25,928 с относительным расхождением 0,000278%. Условия источника: Vero, VACV Copenhagen. Точные строки и ID опытов находятся в `vacv_2018_published_si.csv`.

`vacv_camphor2018_publication.py` сравнивает канонические изомерические SMILES и меняет **одну** ранее не встречавшуюся тестовую структуру: прогноз 25,915342 → 280,411765. Используются только SMILES, опубликованные измерения и независимая метка обучения для контроля источника. Конкурсные CC50/IC50 теста, Title и другие поля в прогноз не входят. Соединение **8** исключено: его SI в обучении расходится с публикацией, поэтому перенос на эту подгруппу не обоснован.

Команда: `.venv/bin/python vacv_camphor2018_publication.py`. Отчёт с контрольными суммами — `camphor2018_release.json`. Kaggle подтвердил публичный MSE **818 462,00900** против **818 823,84447** у предыдущего файла. Новый результат включён в `run_current_best.py`; приватные 70% теста пока неизвестны.
