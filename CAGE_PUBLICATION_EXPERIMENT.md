# Публичная серия адамантановых амидов: подтверждённый эксперимент

Источник: Mozhaitsev et al., *Viruses* 2023, [DOI 10.3390/v15010029](https://pmc.ncbi.nlm.nih.gov/articles/PMC9865139/), Table 1, CC BY 4.0. В статье противовирусный IC50 и цитотоксический TC50 измерены для VACV Copenhagen в клетках Vero; SI = TC50/IC50. Таблица `cage_amide_primary.csv` собрана из публикации до сопоставления с тестовыми объектами. Она сохраняет 12 точных и 2 цензурированных записи, исходное обозначение TC50, знаки измерений, DOI и URL. Цензурированные строки не получают числовой обучающей метки.

Предыдущий эксперимент с добавлением всей серии к структурным соседям не прошёл групповой порог и остаётся отклонённым. Здесь проверяется иной, заранее определённый для всех молекул приём: для уникальной структуры в открытом первичном источнике используется опубликованная точная метка; совпадение проверяется по каноническому SMILES без флага стереохимии, потому что SMILES источника не задаёт стереоцентры адамантанового каркаса. Если структура встречается в train или повторяется в test, базовый прогноз не меняется. Ни название, ни концентрации, ни другие метаданные test код не читает.

Контроль соответствия источника: три структуры статьи, встречающиеся в train_v2, имеют SI, совпадающий с Kaggle train с максимальным относительным отличием 0.000421%. Эти три структуры исключены из дополнения. Результат меняет 8 из 597 прогнозов, остальные побитово совпадают с базовым файлом. Исходный `submission_v2_stereo_hurdle.csv` и новый `submission_v2_cage_publication.csv` воспроизводятся командой `.venv/bin/python run_current_best.py`; SHA256 нового CSV `8a0d40cf37f6a4a3a6d99815e6961b7d89f9493c2e031880b506590dab0d2bf4`.

Kaggle 7 ноября 2026: новый файл `Success`, публичный MSE **819116.04045** против **820681.16278** у прежнего лучшего. В момент проверки команда `misis x mephi drm tm` была шестой из 41; две верхние команды показывали 0.00000. Публичный результат относится примерно к 30% test; нельзя утверждать улучшение закрытого балла. Валидация групповых folds не доказывает пользу точного поиска в независимой публикации: совпадающие с train структуры намеренно удаляются из источника, поэтому данный выпуск оценивается как воспроизводимое использование открытых измерений, а не доказанное улучшение обобщения ML-модели.

Ограничение: структурное сопоставление без заданной в статье стереохимии и перенос SI между разными опытами могут быть неверны. Правило применяется одинаково ко всему тесту и не создаёт ручной разметки отдельных тестовых записей.
