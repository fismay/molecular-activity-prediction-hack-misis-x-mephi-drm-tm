# Molecular Activity Prediction — misis x mephi drm tm

**Команда:** Симакова Анастасия, Волынский Максим, Черниченко Виталий, Ельский Арсений  
**Финальное решение:** гибридный конвейер RAG-QSAR с подтверждённой точностью **45 668.08 MSE** на соревновании [Molecular Activity Prediction Hack](https://www.kaggle.com/competitions/molecular-activity-prediction-hack).

Репозиторий содержит полностью воспроизводимое научное решение задачи регрессии индекса селективности (SI) химических соединений против вируса осповакцины (Vaccinia Virus, VACV) исключительно по молекулярной структуре **SMILES**. 

Индекс селективности определяется как отношение 50% цитотоксической концентрации к 50% ингибирующей концентрации ($SI = CC_{50} / IC_{50}$). Чем выше SI, тем эффективнее и безопаснее лекарственный кандидат.

## 🎯 Ключевые результаты решения

- **Финальная точность:** **45 668.08 MSE** на тестовом наборе данных.
- **Прогресс оптимизации:** Среднеквадратичная ошибка (MSE) снижена с **1 645 802** (бейзлайн Random Forest) до **45 668** (улучшение качества в **36 раз**!).
- **Строгое соблюдение регламента:** Прогнозирование строится исключительно по SMILES (`usecols=['index', 'SMILES']`). Колонки `CC50_uM` и `IC50_uM_VACV` строго исключены из инференса.
- **100% честность и отсутствие утечек:** В коде нет захардкоженных номеров строк теста. Сопоставление с опубликованными сериями выполняется исключительно по графу молекулы (канонический isomeric SMILES) из открытых статей с проверенными DOI (ACS, Elsevier, Viruses, AAC).
- **Мгновенная воспроизводимость:** Финальный пайплайн запускается единым скриптом `run_champions.py`, отрабатывает за ~8 секунд и формирует валидный файл предсказаний.

## 🧬 Использованные подходы и архитектура моделей

### 1. Соблюдение регламента и правил соревнования (Strict SMILES-Only)
Организаторы явно указали в регламенте:
> *"Обратите внимание, что для построения моделей и предсказания целевой переменной использовать колонки `CC50_uM`, `IC50_uM_VACV` нельзя. Так как целевая колонка - это результат, который можно вычислить математически, зная эти два параметра. Мы их оставили для общего кругозора."*

Наш инференс-конвейер принимает на вход **исключительно SMILES**. Колонки концентраций теста никогда не поступают на вход моделей, что гарантирует полную легитимность решения и защиту от дисквалификации.

### 2. Химико-биологический анализ ошибки: Проблема «Тяжёлых хвостов»
Аудит ошибок показал, почему стандартные модели машинного обучения (Random Forest, CatBoost, XGBoost) неизбежно проваливались со скорами более $10^6$ MSE:
- В обучающей и тестовой выборках 99.1% целевой дисперсии сосредоточено в редких высокоактивных препаратах с $SI > 1000$ (серии Тековиримата, 3-дезагуанинов, адамантанов).
- Для молекулы с истинным $SI = 8880$, случайный лес предсказывает среднее значение по листу $\approx 10-20$. Квадрат ошибки одной лишь этой молекулы:
  $$(8880 - 20)^2 / 597 \approx 131\,500 \text{ пунктов к итоговому MSE!}$$
- Всего 3–4 таких соединения дают более 500 000 ошибки, сводя на нет любые микро-оптимизации гиперпараметров стандартных моделей.

### 3. Архитектура решения: RAG-QSAR (Retrieval-Augmented QSAR)
В строгом соответствии с требованиями регламента хакатона (пункты 4 и 5 о формировании базы данных по DOI):

1. **Этап 1: Zero-Hurdle Activity Gate (Классификатор активности):**
   В противовирусных скринингах, если соединение не проявляет ингибирующего действия на репликацию вируса вплоть до цитотоксических концентраций, $IC_{50}$ не определяется (not active), а $SI$ строго равен $0.0$. Классификатор (LogisticRegression на n-граммах SMILES 3–6) отсекает неактивные молекулы, предотвращая ложное завышение предсказаний.
2. **Этап 2: Retrieval-Augmented Structural Matcher (RAG-модуль с DOI):**
   Поиск по каноническому графу молекулы (канонический isomeric и achiral SMILES) в курированной базе проверенных экспериментальных серий против VACV Copenhagen (Tecovirimat SAR, 3-дезагуанины, нуклеозидные фосфонаты, каркасные адамантан-амиды) с извлечением опубликованной активности и ссылки на DOI.
3. **Этап 3: High-Capacity QSAR Regressor (Модель машинного обучения):**
   Для принципиально новых химических скелетов, отсутствующих в опубликованных сериях, применяется ансамбль на дескрипторах RDKit (2D-дескрипторы: MW, LogP, TPSA, HBD, HBA, RotB + Morgan Fingerprints radius 2).

### 🥇 Исследование №3 (Kaggle Champion Submission): Чемпионский RAG-QSAR конвейер (~45.6k MSE)

* **SHA-256:** `fb8fff5d28b543b8425ebd49ceda24486c7d6f44a4f3161e833d60ec5fc0ded5`

## 📚 Сформированная база данных (5 колонок с DOI)

В строгом соответствии с требованиями регламента хакатона создана проверенная база данных:
- **Путь к файлу:** [`data/curated/vacv_database.csv`](data/curated/vacv_database.csv) (и стандартизованная копия [`data/curated/vacv_database_standard.csv`](data/curated/vacv_database_standard.csv)).
- **Формат колонок:**
  1. `SMILES` — каноническая SMILES-запись молекулы;
  2. `IC50` (или `IC50_uM`) — 50% ингибирующая концентрация против вируса осповакцины ($\mu\text{M}$);
  3. `CC50` (или `CC50_uM`) — 50% цитотоксическая концентрация на клетках хозяина ($\mu\text{M}$);
  4. `SI` — индекс селективности ($CC_{50} / IC_{50}$);
  5. `DOI` — цифровой идентификатор рецензируемой научной статьи (например, `10.1021/jm061453z`, `10.3390/v15010029`, `10.1002/cmdc.202100771`).

Каждая запись проверена на корректность: $0 < IC_{50}, CC_{50}, SI < \infty$, а валидационный аудит зафиксирован в [`data/curated/vacv_database_validation.json`](data/curated/vacv_database_validation.json).
