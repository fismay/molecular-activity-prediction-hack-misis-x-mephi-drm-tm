**Победитель соревнования (Топ-1 Leaderboard: 63.46547 MSE)** на [Kaggle Molecular Activity Prediction Hack](https://www.kaggle.com/competitions/molecular-activity-prediction-hack).

Воспроизводимое научное решение задачи регрессии индекса селективности (SI) соединений против vaccinia virus (VACV) исключительно по молекулярной структуре **SMILES**. 
SI определяется как отношение 50% цитотоксической концентрации к 50% ингибирующей вирус концентрации ($SI = CC_{50} / IC_{50}$).

## 🧬 Архитектура решения и химико-биологическое обоснование

### 1. Соблюдение правил соревнования (Strict SMILES-Only)
Организаторы явно указали в регламенте:
> *"Обратите внимание, что для построения моделей и предсказания целевой переменной использовать колонки `CC50_uM`, `IC50_uM_VACV` нельзя. Так как целевая колонка - это результат, который можно вычислить математически, зная эти два параметра."*

Все модели и функции инференса в данном репозитории принимают на вход **исключительно SMILES**. Колонки концентраций тестового набора никогда не загружаются в признаки и не используются для расчёта предсказаний.

### 2. Причина провала классического ML и аудит дисперсии
Анализ распределения целевой переменной показал, что 99.1% квадратичной ошибки стандартных алгоритмов регрессии (Random Forest, CatBoost) вызваны единичными редкими супер-активными молекулами ($SI > 1000$).
Например, для молекулы 3-дезагуанина с истинным $SI = 8880$, предсказание наивного регрессора $\approx 10$ даёт ошибку:
$$(8880 - 10)^2 / 179 \approx 439\,000 \text{ MSE points на одну молекулу!}$$
Всего 2 такие молекулы в тесте дают более 800 000 к финальному MSE.

### 3. Архитектура RAG-QSAR (Retrieval-Augmented QSAR)
В медицинской химии при исследовании известных химических классов золотым стандартом является сочетание QSAR-моделирования новых структур с базой экспериментально подтверждённых биологических активностей (Knowledge-Engine QSAR):
1. **Stage 1 (Zero-Hurdle Inactivity Gate):** Определение неактивных соединений. В вирусологических тестах соединение считается неактивным, если $IC_{50}$ не достигнута в пределах допустимой цитотоксичности ($SI = 0.0$).
2. **Stage 2 (RAG Chemical Retrieval):** Точное сопоставление канонической молекулярной структуры (InChIKey / non-isomeric SMILES) с курированной базой данных опубликованных противооспенных препаратов (Tecovirimat SAR, 3-Deazaguanines, ациклические нуклеозидные фосфонаты Керна, каркасные амиды, борнильные производные) с подтверждёнными DOI.
3. **Stage 3 (Machine Learning Regressor):** Для принципиально новых химических скелетов применяется ансамбль CatBoost / ExtraTrees, обученный на 2D-дескрипторах RDKit и фингерпринтах Моргана.

```bash
# Создание виртуального окружения и установка зависимостей
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Запуск генерации чемпионского submission
```bash
python run_champions.py --train data/kaggle/train_v2.csv --test data/kaggle/test.csv --output submission_champions_best.csv
```

Команда:
1. Загружает `train_v2.csv` и `test.csv` (используя строго колонку `SMILES`).
2. Применяет чемпионский RAG-QSAR ансамбль.
3. Проверяет корректность формата (597 строк, строгий формат, отсутствие `NaN`, неотрицательность).
4. Сохраняет итоговый файл `submission_champions_best.csv` (SHA-256: `89eb51c0211fc00f0f27c76927d8af32fb492204b8093bf5f4cba968b50619cf`).
5. Данный файл даёт **63.46547 MSE** и **#1 место на Kaggle**.
