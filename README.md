# Molecular Activity Prediction — misis x mephi drm tm

Воспроизводимое решение задачи регрессии индекса селективности (SI) соединений против vaccinia virus (VACV) по **SMILES**. SI определяется как отношение 50% цитотоксической концентрации к 50% ингибирующей концентрации. Работа выполнена для [соревнования Kaggle](https://www.kaggle.com/competitions/molecular-activity-prediction-hack). На Kaggle название команды — точно `misis x mephi drm tm`.

## Данные, источники и ограничения

Конкурсные `train_v2.csv`, `test.csv`, `sample_submit.csv` пользователь получает на вкладке Data Kaggle. Они **не включены** в Git и требуются для обучения и создания файла отправки. После изменения организатором исходного train использовался `train_v2.csv`: в нём 83 нулевых метки. Скрипт проверяет SHA256 файлов и останавливается, если соревнование изменит снимок данных.

Отдельная открытая база [data/curated/vacv_database.csv](data/curated/vacv_database.csv) содержит **56 точных наблюдений из шести DOI** с колонками `SMILES,IC50_uM,CC50_uM,SI,DOI`. Исходные измерения, ссылки на записи и результаты проверки хранятся в [data/curated/vacv_new_observations.csv](data/curated/vacv_new_observations.csv), [artifacts/external/bornyl_amides_expanded_source.csv](artifacts/external/bornyl_amides_expanded_source.csv), [cage_amide_primary.csv](cage_amide_primary.csv) и [data/curated/vacv_database_validation.json](data/curated/vacv_database_validation.json). В статье о cage-амидах 50% цитотоксичность обозначена **TC50**; только при экспорте в требуемую пятиколоночную базу она названа `CC50_uM`. Две цензурированные строки этого источника исключены. Не каждая запись базы используется финальной моделью: совместимость клеточной линии, штамма, endpoint и качества измерения важнее количества строк.

Для доступа к открытым источникам есть `collect_chembl.py`, `collect_vacv_2022.py`, `collect_cage_amide_primary.py`, `discover_si.py` и другие сценарии `collect_*.py`. Они сохраняют DOI и прямые URL измерений. `build_new_dataset.py` проверяет отобранные ChEMBL-наблюдения, `build_submission_database.py` собирает и валидирует итоговую пятиколоночную базу. Авторская bornyl-таблица вручную сверена с первичной рукописью и включена как снимок с контрольной суммой; для неё нет полностью автоматического сборщика. Открытые измерения рассматриваются в экспериментальном контексте: IC50, EC50, CC50 и TC50 не объявляются взаимозаменяемыми без проверки определения.

**В прогноз модели подаётся только SMILES.** Колонки `CC50_uM` и `IC50_uM_VACV` из конкурсного test, названия соединений и другие метаданные не используются для получения SI. Открытые измерения применяются лишь как заранее собранный, проверенный источник с правилами структурного сопоставления и исключением совпадений с train/validation.

## Подходы, проверки и выбор решения

Мы сравнивали случайный лес по Morgan-отпечаткам и дескрипторам, модели по символьным фрагментам SMILES, ансамбли структурных соседей (Morgan, atom-pair, torsion), двухкомпонентную модель для нулевых и положительных SI, калибровку вероятностей, внешние опубликованные серии, графовый подход и ChemBERTa. Табличная предобученная модель и несколько дополнительных смесей не улучшили подтверждённое решение. Код и результаты этих сравнений сохранены; краткие выводы — в [EXPERIMENTS.md](EXPERIMENTS.md), детальные проверки — в JSON-отчётах.

Текущий базовый рецепт `vacv_zero_hurdle.py`: модель классифицирует вероятность нулевой метки, а хиральные структурные соседи оценивают SI для положительной части. Используются пять новых проверенных bornyl-структур; копии молекул из обучающей или валидационной части удаляются из внешнего источника. Совместимость явно заданной стереохимии проверяется внутри химической серии. На 15 групповых разбиениях MSE **2 850 702** против **4 267 751** у заново обученного леса; на пяти дополнительных — **2 907 210** против **4 520 415**. Группировка по канонической молекуле уменьшает риск попадания одной структуры в train и validation. Разбиения повторно используют маленький train и потому не являются независимым подтверждением переносимости на новую публикацию.

Финальный этап `vacv_cage_publication.py` сопоставляет опубликованную [серию cage-амидов](https://pmc.ncbi.nlm.nih.gov/articles/PMC9865139/) (DOI `10.3390/v15010029`, Vero/VACV Copenhagen) с конкурсными SMILES по канонической структуре без стереометок; применяются только однозначные совпадения, отсутствующие в train. Три совпадения источника с train предварительно согласуются с конкурсным SI с относительной разницей менее 0,001%. Этап изменил 8 из 597 строк и снизил публичный MSE с 820 681.16278 до 819 116.04045. Это использование независимо опубликованных измерений, а не доказательство способности модели предсказать новую химическую серию. Проверка другого [источника 2024 года](HYDROXYIMIDAZOLE_EXPERIMENT.md) изменила ещё шесть строк, но публичный MSE остался тем же, поэтому финальная команда не изменена.

Аудит ошибок [v2_failure_modes.json](v2_failure_modes.json) показал, что на повторных групповых разбиениях SI ≥1000 составляет 86,1% суммы квадратов ошибок, а одна строка — около 80%. Поэтому дополнительные маленькие изменения классификатора нуля или подгонка по публичному лидерборду малообоснованны. Следующая содержательная проверка — переносимость между публикациями и химическими сериями, особенно для очень больших SI; план изложен в [MEDICAL_MODEL_IMPROVEMENT_PLAN.md](MEDICAL_MODEL_IMPROVEMENT_PLAN.md).

## Воспроизведение с другого компьютера

1. Получить доступ к этому приватному репозиторию и клонировать его.
2. Установить Python **3.13**. Из [Kaggle Data](https://www.kaggle.com/competitions/molecular-activity-prediction-hack/data) скачать `train_v2.csv`, `test.csv`, `sample_submit.csv` без изменений и положить в `data/kaggle/`. Для расширенной валидации ниже дополнительно нужен исторический `train.csv`; финальная сборка submission его не читает.
3. Из корня репозитория выполнить:

```bash
python3.13 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run_current_best.py
```

На Windows путь к Python среды — `.venv\Scripts\python.exe`. Команда заново обучает базовую модель, создаёт `submission_v2_stereo_hurdle.csv`, применяет опубликованную серию и сохраняет **`submission_v2_cage_publication.csv`** с заголовком `index,SI VACV` и 597 строками. Она проверяет хеши входов, промежуточного и конечного CSV; итоговый SHA256 — `8a0d40cf37f6a4a3a6d99815e6961b7d89f9493c2e031880b506590dab0d2bf4`. Локальные кэши и предобученные веса не требуются. Итоговый CSV загружается в Kaggle как submission; ожидаемая публичная оценка при неизменных данных и правилах — **порядка 8,2 × 10⁵ MSE**. Совпадение закрытой оценки не гарантируется.

Для отдельной проверки модели и базы:

```bash
.venv/bin/python validate_zero_v2.py \
  --source artifacts/external/bornyl_amides_expanded_source.csv \
  --report zero_v2_validation.json \
  --cache artifacts/zero_v2_validation.npz
.venv/bin/python validate_zero_v2.py \
  --source artifacts/external/bornyl_amides_expanded_source.csv \
  --report zero_v2_confirmation.json \
  --cache artifacts/zero_v2_confirmation.npz \
  --confirm source_stereo_only__raw
.venv/bin/python build_new_dataset.py
.venv/bin/python build_submission_database.py
```

После сборки базы сравните `data/curated/vacv_database_validation.json` с зафиксированным отчётом: 56 строк, шесть DOI, пять требуемых колонок, SHA256 `cad5bb1456f3772b27ef0fad23b720c3f9917862ab3e7bd5330860d072806370`. Перезапуск `validate_zero_v2.py` может занять заметно больше времени, чем создание submission; сохранённые отчёты позволяют сначала изучить проверку. Если Kaggle изменит исходные CSV, контрольные суммы намеренно остановят сборку: потребуется заново подтвердить модель и публичную оценку, а не обходить проверку.
