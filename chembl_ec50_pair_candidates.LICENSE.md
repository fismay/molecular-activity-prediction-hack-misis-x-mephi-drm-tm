Changes: selected exact unflagged EC50 and CC50 measurements in the same document and molecule; retained only unambiguous one-to-one pairs; computed candidate ratios; added source URLs, DOI and review status. Assay conditions still require review. These records are candidates requiring endpoint and assay context review, not verified competition labels. No private Kaggle rows are included in this CSV.
