# Adaptive structural recipe, 7 November 2026

**Hypothesis.** The confirmed `source_stereo_only__raw` recipe handles the rare, very high SI training series better, while `source_stereo__raw` (half forest and half stereochemical neighbor conditional estimate) is better for the bulk of lower SI labels. Selection uses the model's own SI prediction, never a test label or test concentration.

**Predefined rule.** If the confirmed baseline predicts SI < 5000, use `source_stereo__raw`; otherwise retain `source_stereo_only__raw`. The threshold and full alternative weight were selected on 15 existing canonical-group validation folds. On those folds the pooled MSE changed from 2,857,929 to 2,799,693. A previously computed five-fold confirmation cache gave 2,906,529 → 2,847,328; that cache had already been examined in earlier research, so it is supporting evidence only.

**Fresh confirmation.** `validate_v2_adaptive_gate.py` fixes seed 48373 and retrains both components on five new canonical-group folds. The candidate pooled MSE is 2,752,762 versus 2,788,231 for the unchanged baseline, an improvement of 1.27%. It improves three of five folds; two folds worsen slightly. These splits reuse the same small training set, so the result does not establish performance on an independent publication or Kaggle private split. The full metrics are in `v2_adaptive_gate_confirmation.json`.

**Candidate release.** Run `.venv/bin/python run_adaptive_candidate.py` after placing the Kaggle input files as described in README. The runner first rebuilds the exact confirmed baseline and publication layer, then applies the fixed gate to the saved model, preserving the eight independently published cage-amide measurements. `vacv_adaptive_gate.py` checks every input snapshot, replays the saved model, tests submission order and validates the source overlay. Its output has 597 finite nonnegative predictions, SHA256 `c72198bca88d91fafec88d442d3c6b029b7639d666a895e4ee90b039722f7442`.

**Distribution shift warning.** The gate selects the alternative for 596 of 597 test rows before source overrides, whereas its rationale came from a training outlier. The public score must be measured, and a worse score leaves `run_current_best.py` as the final pipeline. No test concentrations, titles, or manually assigned test labels enter this candidate.
