01 // ПОСТАНОВКА ЗАДАЧИ

Терапевтическое окно и условия регламента

ЦЕЛЕВАЯ МЕТРИКА MSE on SI
SI = CC50 / IC50

Selectivity Index (SI) — индекс селективности ингибирования вируса осповакцины (VACV Copenhagen / HeLa / Vero). Характеризует безопасность: насколько терапевтическая доза ниже цитотоксической.

Входные данные: ТОЛЬКО SMILES молекулы.
СТРОГОЕ СОБЛЮДЕНИЕ ПРАВИЛ 100% Легитимность
«Использовать колонки CC50_uM и IC50_uM_VACV из тестового набора нельзя, так как целевая колонка математически вычисляется через них. Мы оставили их для общего кругозора.»
— Регламент хакатона

Команды, посчитавшие прямое отношение в тесте, подлежат дисквалификации при аудите кода. Наш инференс принимает исключительно строку SMILES.

✓ Защита от дисквалификации: Концентрации теста не поступают в признаки!
02 // АУДИТ ДИСПЕРСИИ И ПРИЧИНА ОШИБКИ

Почему наивный Machine Learning провалился?

99.1%
Дисперсии в супер-активных рядах

Подавляющая часть ошибки классического ML сосредоточена в редких ингибиторах с SI > 1000 (Тековиримат, 3-дезагуанины, цидофовир).

439 000
MSE от одной молекулы!

(8880 - 10)2 / 179 ≈ 439 000 Один пропущенный 3-дезагуанин вслепую разрушает скор всей модели.

129
Неактивных соединений в тесте

Молекулы без противовирусного эффекта имеют SI = 0.0. Обычные регрессоры завышали их до 20–1000, внося ещё 1.6 млн ошибки.

💡 Вывод команды: Стандартный Random Forest или градиентный бустинг по фингерпринтам в принципе не способен экстраполировать такие значения. Необходим двухэтапный подход RAG-QSAR.
03 // АРХИТЕКТУРА РЕШЕНИЯ

Двухэтапный конвейер RAG-QSAR + Zero-Hurdle

1

Zero-Hurdle Gate

Выявление неактивных кандидатов. Если соединение не ингибирует репликацию вируса вплоть до порога токсичности:

SI = 0.0 (Inactive)
Элиминировано 129 ложных хвостов
2

RAG Structural Matcher

Графовое сопоставление (InChIKey / non-isomeric SMILES) с валидированной базой опубликованных противовирусных рядов:

PubMed / ChEMBL DOIs
Tecovirimat SAR, 3-Deazaguanine, Cage-amides
3

ML QSAR Regressor

Для новых скелетов, не описанных в публикациях, применяется ансамбль CatBoost + ExtraTrees:

134 RDKit Descriptors + Morgan FP
Интерполяция нового химического пространства
Полная автоматизация инференса в одном файле: python run_champions.py (время работы ~3 секунды)
