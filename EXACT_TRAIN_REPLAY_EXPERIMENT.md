# Точное сопоставление структур train и test

`train_v2.csv` и `test.csv` содержат 29 совпадающих канонических SMILES с учётом стереохимии; у каждой совпавшей обучающей структуры только одна метка. Две из этих обучающих строк размечены как Variola-only и исключены по происхождению обучающей метки. Остальные 27 размечены с vaccinia в исходном описании. Это правило использует метаданные **только обучающей части** для контроля качества. Из test читаются лишь `index` и `SMILES`; `Culture`, `strain`, `Title`, `CC50_uM`, `IC50_uM_VACV` не читаются.

`vacv_exact_train_replay.py` заменяет прогноз текущего лучшего пайплайна на обучающую метку при точном совпадении стереоструктуры с одной из 27 VACV-аннотированных строк. Для остальных 570 тестовых строк прогноз сохраняется. Максимальное изменение — 79.656 единицы SI, сумма квадратов изменений — 7014.437. Контрольные суммы входных конкурсных файлов и базового прогноза зафиксированы, итоговый SHA256 — `b084f8031b0ac1aa207171abf0aa89795dce66d3de015bc97f6c3b5c60e57f83`.

Запуск после размещения трёх конкурсных CSV в `data/kaggle/`: `.venv/bin/python run_exact_train_replay_candidate.py`. Групповая валидация специально разносит одинаковые структуры по одному fold, поэтому **не может оценить перенос метки для exact train/test дубликатов**. Кроме того, идентичная структура может дать иной SI при другой клеточной линии или условиях опыта. Кандидат является отдельным экспериментом и не заменяет `run_current_best.py` до результата Kaggle.
