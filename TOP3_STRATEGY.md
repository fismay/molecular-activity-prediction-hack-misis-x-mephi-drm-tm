# Стратегия выхода в топ-3 — 7 ноября 2026

## Положение

Публичный Kaggle MSE команды `fismay` — **4 006 684.58056**, место **10**. Третье место показывает **0.00000**, пятое — **558 659.21787**. Публичный балл рассчитан примерно по 30% test; финальное место определяется оставшимися 70%. Метод других команд по таблице неизвестен. Нулевые результаты сами по себе не доказывают нарушения правил.

Организатор запрещает использовать `CC50_uM` и `IC50_uM_VACV` для построения модели и предсказаний. Вход выпуска — только SMILES.

## Приоритеты

1. Разобрать режим SI=10000 (81 из 320 train-строк) и его связь с химическими сериями и способом записи SMILES. Проверять гипотезы только на train. Оценить уверенность модели на test без доступа к SI.
2. Измерить сдвиг train/test по символьным токенам, каркасам и расстояниям Tanimoto. Основную оценку кандидатов делать при группировке одинаковых структур и отдельно при отсечении химических серий. Исключать внешние копии validation из каждого обучающего fold.
3. Проверить ансамбль разных разрешённых представлений: символьные n-граммы, синтаксис исходного SMILES, Morgan, atom-pair и RDKit fingerprints. Калибровать итоговый SI на out-of-fold прогнозах. Сложную модель добавлять только после выигрыша на новых разбиениях.
4. Внешние SI и пары CC50/IC50 включать лишь после проверки вируса, клеток, длительности, единиц, знака измерения, DOI и дублей. Текущие внешние кандидаты покрывают мало test-структур и неоднородны; автоматическое добавление уже ухудшало публичный балл.
5. Выпускать CSV только при устойчивом крупном выигрыше на нескольких схемах проверки. Сверять 597 строк, порядок `index`, точные заголовки и конечность чисел. Публичный балл использовать для подтверждения, без многократной настройки весов по скрытым меткам.

## Критерий решения

Пятое место опережает нас примерно на 3.45 млн MSE; мелкий подбор параметров не закроет разрыв. Приоритет — найти сдвиг данных или новый допустимый сигнал в SMILES, который даёт **кратный** выигрыш на строгой валидации. Кандидат с выигрышем менее 1% на перекрывающихся fold не заменяет текущий лучший выпуск. Топ-3 — цель, но гарантировать его при 320 train-молекулах и таком разрыве нельзя.

## Работа до дедлайна

1. Аудит train/test по тексту и структурам; 1–2 часа.
2. Проверка новых представлений и калибровки на фиксированных fold; 4–6 часов.
3. Новые fold для сильнейшего кандидата и отправка Kaggle при крупном выигрыше; 1–2 часа.
4. Повторный запуск лучшего pipeline, сверка CSV и публикация полного кода/отчёта в приватном `main`; 2–3 часа.
