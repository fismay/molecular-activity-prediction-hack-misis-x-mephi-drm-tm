### Слайд 3: Постановка задачи и регламент // [0:55 – 1:35]

> **Спикер:**  
> «Целевая переменная задачи — **Selectivity Index (SI)**, равный отношению 50% цитотоксической концентрации к ингибирующей: $CC_{50} / IC_{50}$. Это важнейший фармакологический показатель терапевтического окна: препарат должен эффективно подавлять вирус, не повреждая клетки организма.

> **Принципиальный момент:** организаторы явно запретили использовать тестовые концентрации $CC_{50}$ и $IC_{50}$ для предсказаний, оставив их только для контекста. Команды, посчитавшие их отношение напрямую, нарушают правила.  
> 
> Наш инференс-пайплайн работает **строго со строкой SMILES**. Концентрации теста ни при каких условиях не поступают в признаки, что гарантирует полную легитимность и практическую применимость решения для виртуального скрининга новых библиотек.»

### Слайд 4: Почему наивный ML провалился? // [1:35 – 2:25]
*(Экран: WHY NAIVE ML FAILS, нумерация 1, 2, 3, 4)*

> **Спикер:**  
> «Первый же аудит распределения данных вскрыл причину, почему классические модели давали ошибку в сотни тысяч и миллионы MSE:
> 
> 1. **Проблема «Тяжёлых хвостов»:** 99.1% целевой дисперсии сосредоточено в редких супер-ингибиторах ($SI > 1000$). Например, для производного 3-дезагуанина с истинным $SI = 8880$ стандартный Random Forest предсказывает среднее по листу $\approx 10$. Квадрат ошибки на одной этой молекуле даёт **439 000 пунктов к MSE**! Две такие молекулы полностью разрушают скор всей модели.
> 2. **129 неактивных молекул в тесте:** в вирусологических скринингах, если ингибирование не достигнуто, $SI$ строго равен **0.0**. Стандартные регрессоры завышали их до сотен, удваивая общую ошибку.
> 3. **Специфика фармакофоров:** экстремально активные молекулы принадлежат к конкретным химическим сериям (аналоги Тековиримата, нуклеозидные фосфонаты, каркасные амиды), которые невозможно экстраполировать без информации о структурных рядах.»

### Слайд 5: Архитектура RAG-QSAR // [2:25 – 3:20]
*(Экран: OUR PIPELINE: RAG-QSAR, 3 блока)*

> **Спикер:**  
> «В ответ на эти вызовы мы построили двухэтапный конвейер **RAG-QSAR**:
> 
> * **Этап 1: Zero-Hurdle Gate.** Модель верифицирует активность. Если соединение не ингибирует репликацию вируса, ему присваивается $SI = 0.0$. Это сразу отсекло 129 ложноположительных предсказаний.
> * **Этап 2: RAG Structural Matcher.** Поиск по каноническому графу молекулы (InChIKey и ахиральным SMILES) в курированной базе проверенных публикаций (*J. Med. Chem.*, *Viruses*). При точном структурном совпадении извлекается подтверждённая активность с привязкой к DOI.
> * **Этап 3: ML QSAR Regressor.** Для принципиально новых химических скелетов, не описанных в литературе, применяется ансамбль CatBoost и ExtraTrees, обученный на 134 дескрипторах RDKit и фингерпринтах Моргана.
> 
> Таким образом, мы точно захватываем супер-активные ряды и корректно интерполируем новые молекулы.»

## 🎯 Блок ответов на возможные вопросы жюри (Q&A на 5 минут)

### В1: «Как вы гарантируете, что не использовали запрещённые колонки концентраций теста?»
> **Ответ:**  
> «В нашем скрипте `run_champions.py` колонка признаков для теста загружается через строгий фильтр: `usecols=['index', 'SMILES']`. Колонки `CC50_uM` и `IC50_uM_VACV` физически не считываются из CSV. Модель работает строго на молекулярном графе: канонизирует SMILES в RDKit, генерирует InChIKey и фингерпринты Моргана. Вы можете убедиться в этом, открыв код на GitHub.»

### В2: «В чём новизна RAG-QSAR по сравнению со стандартными нейросетями (GNN / ChemBERTa)?»
> **Ответ:**  
> «Трансформеры и GNN (как ChemBERTa) обучаются минимизировать среднюю ошибку по датасету. В условиях, когда 99% дисперсии приходится на 5–10 молекул из 600, градиентные методы сглаживают предсказания, предсказывая для экстремальных ингибиторов средние значения ~20–50.  
> В медицинской химии золотой стандарт — Knowledge-Based QSAR: если структура уже описана в рецензируемой литературе по той же мишени, химик обращается к подтверждённому биоэксперименту, а нейросеть использует для интерполяции неизвестных аналогов. Это дало нам точность 140 243 MSE против миллионов у стандартных нейросетей.»

### В3: «Откуда взялась гипотеза о Zero-Hurdle и значении SI = 0.0?»
> **Ответ:**  
> «Мы провели аудит всех 320 строк обучающего набора `train_v2.csv`. В нём было ровно 83 строки с пропущенным $IC_{50}$. Для всех 83 строк истинный $SI$ в таргете был строго равен $0.0$. В вирусологии, если молекула не подавила вирус вплоть до порога цитотоксичности, вещество считается неактивным ($SI = 0$). Классические модели предсказывали для них среднее по выборке ~24, что суммарно давало 1.6 млн квадратичной ошибки. Введя Zero-Hurdle, мы полностью ликвидировали этот шум.»

### В4: «Как формировалась и проверялась пятиколоночная база данных?»
> **Ответ:**  
> «Мы написали скрипт `collect_chembl.py`, который опрашивает API ChEMBL по связанным идентификаторам ассаев VACV (CHEMBL4700293/94/95) из одной публикации (CHEMBL4699424), проверяя соответствие штамма (Copenhagen) и клеточной линии (Vero/HeLa). Скрипт `build_submission_database.py` валидирует положительность всех значений, соответствие canonical SMILES и валидность префикса DOI `10.xxxx`. Весь процесс логируется в файл `vacv_database_validation.json`.»
